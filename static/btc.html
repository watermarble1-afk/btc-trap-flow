SIGNAL GUIDE 현재 엔진 해석 · 용어 상세

COMPRESSION이평 압축/꼬임. 단기 이평들이 서로 가까워져 방향성이 약해진 상태. 아직 LONG/SHORT 진입 신호라기보다 다음 방향이 만들어지기 전 준비 구간.
RELEASE L / S꼬인 이평이 한쪽으로 풀리기 시작. L은 위쪽, S는 아래쪽으로 방향 생성이 시작되는 단계. 새 추세가 태어나는 초입 후보.
ALIGN L / S이평 배열이 방향대로 정돈된 상태. L은 상승 정배열, S는 하락 역배열. 타점 자체보다 현재 추세 방향과 구조가 살아 있음을 확인하는 상태 신호.
EXPAND L / SEXPANSION = 이평 이격이 벌어지며 추세가 확장. ALIGN 이후 실제로 방향 쪽 힘이 붙는 확인 단계. 이미 움직임이 진행된 뒤 찍힐 수 있음.
MA HIT L / S추세 중 가격이 이평 지지/저항 구간으로 되돌아오는 이평치기. 바로 반대 추세로 판단하지 않고, 기존 BIAS 안에서 눌림·반등 과정을 추적하는 단계.
REALIGN L / S이평치기 후 기존 방향 배열을 다시 복구. 네 이평매매에서 중요한 타점 후보. L은 눌림 후 상승 배열 복구, S는 반등 후 하락 배열 복구.
RE-EXP L / SRE_EXPANSION = REALIGN 뒤 다시 발산. 이평 지지/저항과 배열 복구 후 실제로 기존 추세가 재개되는지 확인하는 신호. REALIGN보다 확인은 늦지만 재발산 확인 성격이 강함.
RE-COMP재꼬임 = 한번 풀렸던 단기 이평이 다시 수렴. 기존 추세의 추진력이 약해지고 방향을 다시 고르는 구간. RE-COMP 자체는 반대 진입 신호가 아니며, 이후 RELEASE L/S 방향을 확인.
BREAKDOWN현재 큰 방향 구조가 무너지는 단계. 단순 눌림이 아니라 중기 이평/VWAP 구조까지 훼손될 때 기존 BIAS를 유지하지 않고 방향을 다시 판단.
INVALIDATION현재 시나리오 무효화 기준 가격. 손절가가 아니라, 이 가격대까지 구조가 깨지면 현재 LONG/SHORT BIAS를 다시 봐야 한다는 엔진 기준.
